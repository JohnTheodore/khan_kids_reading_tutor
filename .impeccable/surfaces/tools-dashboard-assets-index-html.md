# Parent reading dashboard

Mode: Operate. The user approved a full reading-journey dashboard and an
original, warm, gently Khan-adjacent visual refresh; this pins the direction.
The build is code-led for this native-data interface, not a decorative image.

Grounded directions considered: a family practice planner, a reading conference
sheet, a phonics scope-and-sequence wall, a library reading passport, a mastery
rubric/reading journey map, a weekly parent progress letter, and a curriculum
field guide. Seed `35fc4f67` assigned the fifth direction: the mastery map.
It honors the already approved brief. Foreign art systems were declined as
parent-facing identities; their useful disciplines are structural honesty
(textiles), clear layer separation (stagecraft), persistent orientation
(console), economy of color (WPA poster), legible evidence (instruments), and
explicit unknown states (depot blind), not borrowed visual motifs.

## Direction contract

THESIS: A parent sees today's reading focus, this week's growth and the
remaining reading journey without interpreting automation logs.

OWN-WORLD: A mastery rubric translated into a warm ivory surface, sky-blue
actions, leaf-green verified evidence, clear system typography and quiet rules.
Original SVG icons; no Khan artwork, mascots, copied layouts or screenshots.

STORY: Selected reader → next practice and recent mastery → journey → milestone → exact lesson
variant, dated scores and mastery reasoning. Sync results retain their own
verified/proposed distinction.

FIRST VIEWPORT: Reader selection and sync remain immediately available;
selected-reader practice and weekly gains lead before technical setup. A persistent dropdown switches readers; static meters show recorded evidence, and a determinate sync bar advances through workflow stages without visible percentages or looping animation. The signature
interaction is opening a milestone to inspect its evidence without leaving the
journey. Missing records never look like zero ability.

FORM: Native details/summary disclosure and restrained semantic colors.
Responsiveness changes structure, not truth; archived readers remain read-only.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
