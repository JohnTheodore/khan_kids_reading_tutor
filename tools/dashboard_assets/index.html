              Connection & setupManage your local app

              Checks local installation—not live tablet connectivity. The sync verifies the tablet and account.

                First-time setup

                1. Follow the step-by-step setup guide (opens a new tab) to install the local tools.
                2. In Khan Kids, convert your account to a Class Account. Name the teacher dad. Open Teacher Settings and enable Show students Assignments first.
                3. Create your private student mapping and credentials file. Your reader's name stays local; public records use an alias.
                4. For wireless, enable Developer options and Wireless debugging, pair ADB, and save the private tablet configuration.
                5. For USB, enable USB debugging, connect a data cable, authorize your computer, then launch with --serial YOUR_USB_SERIAL.

                If the tablet disconnects

                After reboot, wireless currently needs a physical unlock and Wireless debugging re-enabled. USB normally avoids that toggle, but unattended reboot recovery is not yet verified.

                If a prize prompt or unfamiliar screen blocks startup, the tutor stops without restarting. Leave it visible for inspection; captures stay in private/startup-blocked-*.
